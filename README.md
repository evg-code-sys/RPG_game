# FIRST PROJECT
**Простой проект на языке программирования Python, представляет собой пример механики RPG-игры.**

_Используются следующие компоненты ООП:_ 
1. Полиморфизм;
2. Наследование;
3. Композиция.

> Ничего сложного код не делает, показывает в терминале инвентарь, добавить вещь, удалить вещь, и ещё пару приколюх, почитайте код, сами поймете.
